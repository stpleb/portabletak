ATAK QR Setup

Tailscale: works on Wi-Fi and cellular while the phone's Tailscale app is on (signed in to the same account).
Scan this from inside ATAK (a phone's camera app cannot use it): ATAK → Settings → Network Preferences → Manage Server Connections → add a server → tap the QR icon. Then sign in with this user's name and password.
First time on this phone? Import the ATAK Trust Package (for QR) from Client Setup first.
Is this page open on the phone itself? Tap Open in ATAK instead of scanning.
Remote access set up? The phone gets two servers: this one and "server name (Tailscale)", which keeps working over cellular while the phone's Tailscale app is on.
Open in ATAK
This QR contains a single-use enrollment credential.
Expires in 15 minutes.
Do not share or reuse it.

iTAK QR Setup

Tailscale: works on Wi-Fi and cellular while the phone's Tailscale app is on (signed in to the same account).
Scan this from inside iTAK (a phone's camera app cannot use it): iTAK → Settings → Network → Servers → + → Scan QR, then sign in with this user's name and password.
First time with this drive on this iPhone? Install the iPhone Trust Profile from Client Setup, then switch it on in Settings → General → About → Certificate Trust Settings (otherwise iTAK says "error connecting to the server").
This QR has the server settings only (no user credential or certificate). The iTAK Package is the alternative that needs no sign-in.
