PortableTAK Setup for Windows

Makes a PortableTAK USB drive on this computer (Windows 11, administrator rights).

1. Unzip this folder (do not run it from inside the zip).
2. Plug in a USB drive of 16 GB or more. It will be erased.
3. Double-click "PortableTAK Setup (Windows)" and click Yes when Windows asks.
4. Choose a ready-to-use drive (name and passwords now) or a blank drive.
5. Pick the USB drive and type the confirmation phrase. Wait 6-10 minutes.

The first run on a computer may install WSL (Windows Subsystem for Linux) and
ask you to restart; then run setup again.
