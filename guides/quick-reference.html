Accounts and passwords

  • Dashboard: user administrator + the administrator password chosen at setup.
  • Client password: protects the certificate packages; phones use it during QR enrollment.
  • Phone users: created in Users. Passwords: 8+ characters (12+ recommended).
  • Too many wrong sign-ins lock sign-in for a few minutes (per device).

Remote access (cellular) checklist

1One free Tailscale account for everything (tailscale.com).
2Remote Access → Enable remote access → approve link → Finish setup (server needs internet). Once per drive; the same on node, Windows and Mac.
3Tailscale app on every phone, same account, switched on.
4Set up phones afterwards: ATAK QR Setup or ATAK Package (both add the Tailscale server); iPhone: iTAK QR Setup with "Phone is on: Tailscale", or the iTAK Remote Package.
5Test with the phone's Wi-Fi off.

Rules of thumb

  • Every device needs its own callsign; two devices with the same callsign cannot both connect.
  • Make each drive with PortableTAK Setup. Never clone a set-up drive: clones share keys and users.
  • A node with internet on its Ethernet shares it with its Wi-Fi clients automatically.
  • Phones keep cellular for internet when the node has none.
