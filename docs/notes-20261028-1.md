PortableTAK 2026.10.28.1 (test release): voice server for push to talk, OpenMANET talk group link, and security fixes.

**Voice (push to talk)**
- PortableTAK now runs a Mumble voice server on port 64738 (TCP and UDP), for the TAK PTT ATAK plugin.
- Phones sign in with their TAK certificate, so there are no extra accounts. Users who are deactivated in OpenTAKServer are locked out of voice too.
- Callsigns are the voice names, and nobody can take another user's callsign.
- **Voice history:** every transmission is kept for 7 days with sender, channel, time, length and position. Phones list it, play it and show it on the map, over HTTPS with their certificate.
- **Mesh failover:** the server hands out weekly per-channel keys, so phones can keep talking over the local network (OpenMANET or Wi-Fi) when the server is out of reach.
- The voice server has its own certificate from the drive's certificate authority. The launchers open port 64738.
- **OpenMANET talk groups:** the server joins its LOBBY to OpenMANET talk group 1, so people on the server and people only on the mesh (OpenMANET nodes, the ManetNode plugin) hear each other. Other links: `"talkGroups": "LOBBY=1,Ops=2"` in `opentak/voice.json` (`""` turns it off). One person talks at a time across the link. Talk groups are not encrypted. Needs the server on the mesh's network (an OpenMANET node or a Linux computer); on Mac or Windows hosts talk groups may not get through.
- The guide has a new chapter, "13. Voice (push to talk)", and new troubleshooting rows.

**Security fixes**
- **Voice sign-in:** nobody gets into voice unless PortableTAK's sign-in check lets them in, including while that check is starting or stopped (before, anyone could join under a new name in that window).
- **Certificate enrollment:** OpenTAKServer refuses a certificate request in any name other than the signed-in user's. Before this, one user could get a certificate in another user's name.
- **Tailscale:** the drive's internal services listen on an internal-only address, so tailnet devices reach only the public ports, not OpenTAKServer's internal port or the users worker.

**Tested:**
- Voice against a PortableTAK test copy with a real S22 running the TAK PTT plugin:
  - certificate and password sign-in;
  - channels, listening and talking on several at once;
  - history and map markers;
  - SOS;
  - mesh failover (one phone).
- Talk group link on the test copy, both ways: a talk group radio heard in LOBBY (and saved in history), and LOBBY heard on the talk group.
- Voice sign-in with the sign-in check stopped: a client with no certificate is refused; with it running, certificate and password sign-in work.
- Enrollment refusal, and two full stop and start cycles with the internal address.
- Provision tests pass (the Linux-only tests are skipped on the Mac).
- Not yet tested: two phones talking, Bluetooth headsets, the talk group link on a real OpenMANET node, a real Raspberry Pi or Linux PC.

The TAK PTT plugin is not part of this release.
