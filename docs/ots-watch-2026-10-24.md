# OpenTAKServer watch - 2026-10-24

**New: OpenTAKServer 1.7.14 (2026-10-23).** PortableTAK ships 1.7.13 + its own federation add-on (PR #343 based).

Changes that matter for PortableTAK:
- **Federation: still not in OpenTAKServer.** Issues "Federation" / "Add federation support" are open; PortableTAK's add-on remains the only federation.
- ADS-B and AIS jobs disabled (their libraries were deleted from PyPI). PortableTAK keeps working: its 1.7.13 base is sealed with the wheels already included.
- New DB support for PostGIS/GeoAlchemy2 (new migration + new dependency) - an upgrade would need PostGIS in the drive's PostgreSQL.
- Fixes: ATAK QR enrollment URL includes the streaming port (PR #348), EUD position streaming in cot_parser (PR #353), send_disconnect_cot unbind fix, WinTAK data sync and missions, ATAK Reports and Vx plugins.
- Dependency bumps incl. gevent 26.8, python-socketio 5.16, pyopenssl 26.4, sqlalchemy 2.0.52.

PortableTAK impact: upgrading means rebasing the federation add-on (pt-fed branch) onto 1.7.14 (cot_parser and app.py changed; patch-overlay.py checks the CA file and will refuse if certificate_authority.py changed), re-checking opentakserver_launch.py / eud_handler_launch.py hooks, adding PostGIS, and a full release + regression run.

**Recommendation: wait.** Nothing here is needed by PortableTAK today and no federation upstream; revisit when OTS adds federation or a fix we need.
