PortableTAK 2026.10.26.1 (test release): fixes and additions from testing 2026.10.26 on real hardware (Node01 + S22).

**Video**
- **Watch is under a second behind** (WebRTC); falls back to the previous player (a few seconds behind) when WebRTC cannot connect. Watch no longer freezes on Safari / newer Chrome.
- **TAK ICU feeds**: add a feed of type "TAK ICU"; the dashboard shows the TAK ICU settings (Local Area Network, delivery RTSP, server address `<server>:8554/_in/<feed>`). The server unwraps TAK ICU's video so it plays in browsers, over TCP so nothing is lost over Wi-Fi (no smearing), and starts the feed afresh at each broadcast.
- **Camera / stream URL feeds**: the server pulls RTSP Wi-Fi/IP cameras, RTMP, SRT or HLS links; passwords stay on the drive (shown as `***`).
- Phones on Tailscale get feeds at the server's Tailscale address automatically.
- While a TAK ICU feed exists the server accepts RTSP pushes over TCP only.

**Live Map**
- Dark / light map button; picking an offline map moves to its area, and the map says when you are outside it.
- Opening /map signed out goes to the sign-in page.

**Live Feeds**: ADS-B from the internet falls back to adsb.fi when adsb.lol refuses (rate limit).

**Dashboard**: section icons (TAK badge for ATAK Plugins, the Meshtastic mark for Meshtastic); Federation sits under Remote Access, Video Feeds under Live Feeds.

**Tested on real hardware** (Node01 with the 2026.10.26 drive + these changes, S22): S22 connected, aircraft in ATAK and on the map, plugin sync, offline maps (DFW, Lubbock), TAK ICU video in ATAK and in the browser without errors. Fresh drive from the Mac Setup: see SETUP line in the build. Not yet tested: a real RTSP camera, Safari / iPhone Watch, Skydio with TCP-only RTSP, Meshtastic with a second radio.
