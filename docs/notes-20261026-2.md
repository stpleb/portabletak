PortableTAK 2026.10.26.2 (test release): Linux and Raspberry Pi host, desktop dashboard layout, data packages.

**Runs on Linux and Raspberry Pi OS** (64-bit, x86-64 or ARM, e.g. a Raspberry Pi 4/5 with 4 GB+): plug in the drive and run `sudo bash "Start PortableTAK (Linux).sh"` from its PORTABLETAK volume. After the first start PortableTAK starts by itself when the drive is plugged in and at boot; `sudo portabletak stop` before unplugging. The server and its data stay on the drive.

**Dashboard**
- **Desktop layout** (like OpenTAKServer's web UI): on a computer screen a sidebar of pages (Dashboard, Live Map, every section); phones keep the single scrolling page. The six status cards are two even rows on desktop; sections always appear in the same order.
- **Data Packages**: list the server's data packages (including ones phones share), upload any file (wrapped into a data package) or an ATAK data package, send it to phones (ATAK's "file received", downloaded from this server over Wi-Fi, mesh or Tailscale), download or delete.
- **Video Feeds**: on desktop, live feeds play right on the page; each feed shows its type (Drone / app, TAK ICU, Camera) instead of a type switch; the TAK ICU settings sit below the drone help.

**Tested:** Linux host on Debian arm64 (Raspberry Pi OS stand-in) and Ubuntu 24.04 x86-64 (emulated) with the release's test drive: all 7 services, phones' certificate issued for the computer's address, stop/restart/uninstall. Data package sent from the dashboard to a real S22 (ATAK downloaded it from Node01 and added the KML overlay). Desktop layout and video tiles in the browser. Fresh drive from the Mac Setup: see build. Not yet tested on a real Raspberry Pi or Linux PC.
