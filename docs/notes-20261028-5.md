PortableTAK 2026.10.28.5 (test release): data packages with an official TAK Server, node heat warning, two servers on one mesh, automatic backups.

**Federation with an official TAK Server: data packages**
- A data package an ATAK user sends to someone on a federated official TAK Server now gets there, and the other way. TAK Server federates files as ROL ("create resource" with the file, then "announce package" with who it is for); PortableTAK now speaks that on the existing federation link, and keeps using its own file transfer with other PortableTAK servers.
- The TAK Server admin must turn on mission federation (`allowMissionFederation="true"` on `<federation>` in CoreConfig.xml). The admin sheet on the Federation page says so.
- Data Sync missions are not shared yet.

**Nodes**
- **Heat:** the dashboard shows the node's temperature, and warns above 75 °C (a hot node or USB drive can drop the drive off USB). Warm periods are logged in `logs/temperature.log`.
- **Two servers on one mesh** (two teams link up): a server that starts while another answers on its address takes the next free one (10.41.250.11 and up) and keeps it; if both were already running, the dashboard warns in red. Federate the two to share.
- **Clock:** a node whose clock is behind (no clock battery, no internet) now sets itself from the phones' position reports within 5 minutes, as well as at dashboard sign-in.
- **OpenMANET web push to talk over HTTPS** at `https://10.41.250.10:8445`, so a phone's browser may use the microphone.

**Backups**
- A note on each backup, **Upload a backup** (verified before it is kept, e.g. onto a replacement drive), and **automatic daily backups** keeping the last N (backups you make or upload are never removed).

**Voice**
- The voice watchdog also runs the clock check and automatic backups. TAK PTT 0.1 is now signed by TAK.gov (installed separately; dashboard > ATAK Plugins).

**Tested:**
- Against official TAK Server 5.8 (container): a package from PortableTAK stored on TAK Server and announced to its user, downloaded there with the right SHA-256; a package uploaded by a TAK Server client stored on PortableTAK and its announcement released as a file share pointing at PortableTAK.
- On Node01 (OpenMANET node): heat reading, duplicate-address check, clock set forward from phone reports, HTTPS web page (Chrome on a Samsung S22 allows the microphone there), backup upload/verify/schedule.
- Unit tests: provision (heat, clock, addresses, backups), federation (28 passed).
- Fresh-drive build test: 7 of 7 services.
- Not yet tested: a TAK Server that dials PortableTAK (here PortableTAK dialed), real phones on both servers for packages, Data Sync missions.
